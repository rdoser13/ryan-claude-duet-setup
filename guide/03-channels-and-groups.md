# Step 3: Channels and groups

A channel is a separate chat for one lasting subject. It has its own Claude, its own tasks and its own memory. Use channels so your main chat doesn't turn into a junk drawer.

## My layout

Here's the shape of my setup, with the names swapped for categories:

| Group | Channels |
|---|---|
| Clients | One channel per client |
| Personal Brand | YouTube, Podcast, Website (plus digital PR) |
| Digital Products | One channel per product |
| Personal Life | Bookkeeping, Investing |

The main chat stays for daily rhythm, content, cross-project work, scheduled actions and backups.

## How to create them

Just ask in your main chat:

```
Create a channel called {{CHANNEL_NAME}} for {{WHAT_IT_COVERS}}. Put it in a group called {{GROUP_NAME}}. Don't set up or run anything in it yet.
```

That last line matters. A new channel's Claude may want to start work. Tell it to wait until you ask.

## What goes in a channel vs the main chat

**Put it in a channel when:**
- It's a client (keeps their data separate and easy to exclude from backups).
- It has its own routines (a client's weekly report, a site's pitch routine).
- It has its own rules ("no labels on this client's graphics").

**Keep it in the main chat when:**
- It touches several areas (week in review, task health check).
- It's your personal content engine (X drafts, memes).
- It's a system job (backups, tracker updates).

## Tips

- **Routines live where they post.** A client's routine should live in that client's channel, so its posts land there.
- **Main chat sees all.** Ask your main chat "What's open across all my channels?" and it will check each one.
- **Personal channels can be "hands off".** My investing channel has a standing rule: "Don't set it up or run anything. I just wanted this channel." Claude answers questions there and never places trades.
- **Client work under NDA.** Note it in that channel's memory, and add the client to the exclusion list for backups (step 7).

## Checklist

- [ ] 3 to 6 channels created
- [ ] Each one grouped
- [ ] Client channels marked with any NDA or privacy rule
